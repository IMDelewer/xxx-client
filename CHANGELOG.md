# Changelog

## 0.2.1

- Rework the map editor header, brush tools and layer list with more room for the map.
- Use the client font and icons in the editor, remove outlined labels and soften selection colors.
- Download Japanese, Korean and Chinese fonts when needed instead of bundling them.
- Remove the vortex and keep the original PNG menu background with custom images supported.
- Center menu icons by their visible pixels and simplify connection and map-loading screens.
- Simplify liquid glass, borders and animations while keeping glass enabled by default.
- Match editor panels, popups and fields to the light and dark client themes.
- Reduce UI allocations and bound map preview textures and cache memory.
- Remove documentation screenshots and unused assets from desktop packages.
- Distribute macOS as a DMG with pinned runtime libraries targeting macOS 12.

## 0.1.0

- Initial public release with XUI menus, an editable HUD and a resource catalog.
- Fix catalog pagination crashes.
