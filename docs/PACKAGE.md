# xxx client

Extract the Windows or Linux archive and launch `xxx.exe` or `xxx`.
On macOS, open the disk image and drag `xxx.app` to Applications.
The macOS package requires macOS 12 or later and a supported Metal GPU.
It uses an ad-hoc signature; Apple notarization is not configured.
The Linux package uses Ubuntu 24.04 system libraries.

English, Russian and the standard UI fonts are included. Japanese, Korean
and Chinese fonts are an optional 29 MB download from the official DDNet
repository. Install them in Settings under General. The download is checked
against a pinned SHA256 and saved in your user data directory. The client
can start and play without downloading it.

Liquid glass, light and dark themes, and a custom PNG background are available
in Settings under Appearance. The map editor retains DDNet's tool layout.

Source, documentation and releases: https://github.com/IMDelewer/xxx-client
