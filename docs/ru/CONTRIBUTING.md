# Участие в разработке

Сборка и зависимости описаны в [README](README.md), границы модулей — в
[архитектуре](ARCHITECTURE.md).

- Меню и виджеты добавляйте в XUI. Сетевые и файловые службы держите отдельно
  от экранов. Используйте цвета и размеры из `xui/theme.h`.
- Сохраняйте физику DDNet, сетевой протокол, форматы карт и демо.
- Не добавляйте читы, траектории, подмену клиента/пинга и автоматическое
  исправление игрового ввода. Диагностика доступна только под `DDEV_XX`.
- Новая настройка должна иметь перевод, корректное сохранение и видимость
  зависимых контролов. HTTP и загрузка ресурсов не должны блокировать кадр.
- Форматируйте изменённые C++-файлы через `clang-format`. Обновляйте явный
  список исходников в CMake при добавлении и перемещении файлов.

В pull request опишите проблему, результат и фактически выполненные проверки.
Для визуальных изменений приложите реальные снимки клиента. Если платформа
или сценарий не проверены, укажите это. Сохраняйте авторство и лицензии
заимствованных частей; правила переноса XUI находятся в [PROMT.md](../../PROMT.md).
