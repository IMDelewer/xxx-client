# Устройство xxx client

| Путь | Назначение |
| --- | --- |
| `src/game/client/xui/` | Layout, ввод, темы, виджеты и экраны XUI |
| `src/game/client/components/menu_services/` | Браузер, ресурсы, демо, каталог teedata, системный выбор PNG и предпросмотры карт |
| `src/game/client/components/xxx/` | Косметические компоненты, Dynamic Island и переходы между меню и игрой |
| `src/game/client/dev/`, `src/game/client/xui/dev/` | Диагностика под `DDEV_XX` |
| `src/engine/shared/config_variables_xxx.h` | Настройки xxx |
| `src/engine/client/backend/vulkan/`, `data/shader/vulkan/` | Vulkan и GPU-материалы XUI |
| `src/game/client/prediction/` | Обычная игровая prediction DDNet; это не удалённые игровые помощники |
| `data/languages/xxx/` | Дополнительные переводы |
| `scripts/package_client.py` | Пакет клиента с ресурсами и лицензиями |
| `.github/workflows/build.yml` | Проверка и сборка трёх desktop-платформ |

Клиент не содержит каталога `cheats/`, спуфера, исправляющих ввод помощников,
отрисовки траекторий, хитбоксов, радара и подсказок спасения. Служба
`map_previews` сохраняет картинки и схемы карт для меню, без игрового радара
и расчёта прогресса до финиша.

Физику, протокол, сервер и редактор не следует переписывать ради меню.
Серверные исходники upstream сохранены для локального сервера и тестов;
`SERVER` выключен по умолчанию. Наличие `dev/` в исходниках не включает его
команды в обычную сборку.

Добавляя настройку, одновременно добавляйте её перевод, видимость зависимых
контролов и обработку сохранённого значения. Добавляя файл, обновляйте явный
список CMake. Отладочные функции не должны становиться пользовательскими
настройками в release.
